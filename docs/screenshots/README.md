# Scrimnet screenshot guide

Capture these views from the deployed beta using realistic but non-sensitive test data. Save optimized PNG or WebP files in this directory and link them from the root README.

Recommended captures:

1. `marketplace.png` — verified-team marketplace with one future scrim listing.
2. `team-roster.png` — team profile, roster roles, and invite interface.
3. `create-scrim.png` — populated post-a-scrim form.
4. `incoming-request.png` — captain/manager view of an incoming scrim request.
5. `match-workspace.png` — confirmed match with check-in status and private chat.
6. `admin-queue.png` — admin verification and/or moderation queue, with personal information removed.

Do not capture real school emails, invite links, authentication tokens, database identifiers, or private conversations without consent.
